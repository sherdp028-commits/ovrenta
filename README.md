# Чат-бот для ВКонтакте на Claude

Бот отвечает на личные сообщения сообщества ВКонтакте. Ответы генерирует Claude (Anthropic).
Он помнит переписку с каждым собеседником, показывает «печатает…», пока готовит ответ,
и сам разбивает длинные ответы на несколько сообщений.

- Работает через **Bots Long Poll API**: публичный адрес и HTTPS-сертификат не нужны,
  достаточно любого компьютера или сервера с доступом в интернет.
- Модель по умолчанию — `claude-opus-5-5`. Модель и глубину размышлений можно поменять в `.env`.
- Характер и тематику бота задаёт файл `system_prompt.txt`, код для этого трогать не нужно.

## Что понадобится

1. Python 3.10 или новее (или Docker).
2. Сообщество ВКонтакте, в котором вы администратор.
3. Ключ API Anthropic: [platform.claude.com/settings/keys](https://platform.claude.com/settings/keys).
   API платный, оплата идёт за использованные токены.

## Настройка сообщества ВКонтакте

Пункты меню у ВКонтакте иногда переименовываются, но разделы остаются примерно такими:

1. **Сообщения:** «Управление» → «Сообщения» → включите «Сообщения сообщества».
2. **Возможности ботов:** там же, «Настройки для бота» → «Возможности ботов: включены».
   Здесь же можно включить кнопку «Начать» и разрешить добавлять сообщество в беседы.
3. **Ключ доступа:** «Управление» → «Работа с API» → «Ключи доступа» → «Создать ключ».
   Отметьте права **«Управление сообществом»** и **«Сообщения сообщества»**.
   Получится значение для `VK_TOKEN`.
4. **Long Poll API:** «Работа с API» → вкладка «Long Poll API»:
   - Long Poll API: **включено**, версия API: **5.199**;
   - «Типы событий» → отметьте **«Входящее сообщение»**.
5. **ID сообщества:** число из адреса вида `vk.com/club123456789` или из раздела
   «Основная информация». Это значение для `VK_GROUP_ID`.

## Запуск

```bash
git clone https://github.com/sherdp028-commits/ovrenta.git
cd ovrenta

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env             # Windows: copy .env.example .env
# откройте .env и впишите VK_TOKEN, VK_GROUP_ID и ANTHROPIC_API_KEY

python -m bot
```

После запуска напишите сообществу в личные сообщения — бот ответит.
Остановить бота можно сочетанием `Ctrl+C`.

### Через Docker

```bash
docker build -t vk-claude-bot .
docker run -d --name vk-bot --restart unless-stopped --env-file .env vk-claude-bot
docker logs -f vk-bot            # смотреть логи
```

## Команды бота

| Сообщение | Что делает |
|---|---|
| `Начать` (или кнопка «Начать») | Приветствие |
| `помощь` | Короткая справка |
| `сброс` | Забыть переписку и начать диалог заново |

Всё остальное отправляется Claude.

В **беседах** бот отвечает, только когда к нему обращаются: `@club123456789 вопрос`
или упоминание через «@» в интерфейсе. У каждой беседы своя история переписки.

## Настройки (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `VK_TOKEN` | — | Ключ доступа сообщества (обязательно) |
| `VK_GROUP_ID` | — | ID сообщества (обязательно) |
| `ANTHROPIC_API_KEY` | — | Ключ API Anthropic (обязательно) |
| `BOT_MODEL` | `claude-opus-5-5` | Модель Claude |
| `BOT_EFFORT` | `medium` | Глубина размышлений: `low`, `medium`, `high`, `xhigh`, `max` |
| `BOT_MAX_TOKENS` | `16000` | Предел длины ответа в токенах (вместе с размышлениями) |
| `HISTORY_MAX_MESSAGES` | `40` | Сколько последних сообщений помнить в диалоге |
| `SYSTEM_PROMPT_FILE` | `system_prompt.txt` | Файл с инструкцией для бота |
| `LOG_LEVEL` | `INFO` | Подробность логов |

**Как сэкономить.** Самое заметное снижение стоимости дают `BOT_EFFORT=low`
(для обычной болтовни этого часто хватает) или более дешёвая модель:
`BOT_MODEL=claude-sonnet-5-5` или `BOT_MODEL=claude-haiku-5-5`.
Повторяющееся начало диалога кэшируется автоматически, и такая часть запроса стоит дешевле.

## Как устроен код

```
bot/
  __main__.py   запуск: python -m bot
  config.py     чтение настроек из .env
  vk.py         клиент VK API: Long Poll, отправка сообщений, «печатает…»
  app.py        обработка сообщений и команд, логика бесед
  assistant.py  запросы к Claude и история переписки
tests/          тесты (без сети и без настоящих ключей)
system_prompt.txt  инструкция для бота
```

Несколько деталей:

- **История** хранится в памяти отдельно для каждого чата. Когда она превышает
  `HISTORY_MAX_MESSAGES`, бот оставляет последнюю половину сообщений.
- **Отказы.** Если фильтры безопасности Claude отклоняют запрос, API само повторяет его
  на подходящей запасной модели (параметр `fallbacks: "default"`). Если отказ всё равно
  остаётся, бот вежливо об этом сообщает, а в историю такой обмен не попадает.
- **Ошибки** API (лимиты, сбои сети) не роняют бота: собеседник получает просьбу
  повторить позже, а подробности пишутся в лог.

## Ограничения

- История переписки сбрасывается при перезапуске бота. Чтобы она сохранялась,
  нужно хранить её в базе данных, например в SQLite или Redis.
- Бот понимает только текст. На фото, стикеры и голосовые он отвечает подсказкой.
